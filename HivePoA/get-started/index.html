Get started

  1. Receive an authenticated trust bootstrap outside GitHub and IPFS.
  2. Open Download only after the signed index enables both mirrors.
  3. Verify the SHA-256 locally on the Verify page before running anything.
  4. Storage stays off until you deliberately opt in inside the desktop app.

This page never auto-downloads packages and never silently switches mirrors.
